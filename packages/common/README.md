## @weberon/common

This library provides shared types, constants, and utility functions used across the [@weberon/ui](https://www.npmjs.com/package/@weberon/ui) and [@weberon/generator](https://www.npmjs.com/package/@weberon/generator) packages. The shared types include definitions for templates and other commonly used structures.

For the complete documentation of pdfme, please refer to [this link](https://pdfme.com/docs/getting-started).
